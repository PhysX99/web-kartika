# KARTIKA PRODUCTION — Landing Page

Website landing page dark modern, responsif, dan statis. Tidak memerlukan database, backend, atau biaya server.

## 1. Atur tautan WhatsApp dan YouTube

Buka `script.js`, lalu ubah bagian `LINKS`:

- `whatsappNumber`: nomor WhatsApp dengan format internasional Indonesia, contoh format `6281234567890` (tanpa `+`, spasi, atau angka `0` awal).
- `youtubeUrl`: URL channel YouTube, misalnya `https://www.youtube.com/@NamaChannel`.

Simpan file setelah mengubahnya.

## 2. Hosting gratis dengan GitHub Pages

1. Login atau buat akun di https://github.com/
2. Buat repository baru, misalnya `kartika-production`.
3. Unggah `index.html`, `style.css`, dan `script.js` ke halaman utama repository (root).
4. Buka **Settings → Pages**.
5. Pada **Build and deployment**, pilih **Deploy from a branch**.
6. Pilih branch `main` dan folder `/ (root)`, lalu tekan **Save**.
7. Tunggu proses publikasi. GitHub akan menampilkan alamat website, biasanya `https://username.github.io/kartika-production/`.

## 3. Pasang di TikTok

Salin URL GitHub Pages yang sudah aktif, lalu tempelkan pada kolom Website/tautan di profil TikTok (jika fitur tersebut tersedia untuk akunmu).

## Catatan

- Website ini hanya halaman penghubung; tombol membuka WhatsApp dan YouTube.
- Jangan unggah file ZIP saja. Unggah ketiga file website ke root repository.
- Kamu bisa mengubah teks, warna, dan tampilan melalui `index.html` dan `style.css`.
